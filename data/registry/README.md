# Portable Cricsheet registry

Generated from the [Cricsheet Register](https://cricsheet.org/register/) (ODC-BY 1.0)
and roster membership in the four official match archives identified in
`build_manifest.json`. Attribute Cricsheet when using these derived exports.
Wikidata labels and identifiers are CC0; per-lookup URLs and retrieval dates are
in `../i18n/`.

See `../../docs/phase1-data.md` for column definitions, coverage limitations,
unknown-category handling, and rebuild commands. Empty fields are missing data,
not inferred values. `aliases` is a JSON array stored in one CSV field.

This is training-safe identity data. It contains no held-out test queries or
evaluation annotations.
